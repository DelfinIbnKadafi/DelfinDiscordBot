Delfin Discord Bot

Delfin Discord Bot is a official Delfin's bot discord.

Features

  1. Discord connections
  2. Ai commands with /ask

Installation

  1. Clone this repository first with git clone https://github.com/DelfinIbnKadafi/DelfinDiscordBot.git
  2. Install nodejs and npm if you have not that.
  3. Install al dependencies with npm ci in Discord bot folder.

Run the bot

  1. Install dependencies with npm install.
  2. Copy .env.example to .env and set all environment variables.
  3. Deploy all commands before start the bot if it the first time.
  4. Edit config.json to edit bot configuration.
  5. Start the bot with npm start.

The bot requests the Guilds gateway intent. Keep the bot token private and do not commit .env.
